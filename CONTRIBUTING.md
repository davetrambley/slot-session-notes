# Contributing

Keep changes small, describe the problem they solve, and include reproduction steps. Run `npm test` for changes to calculations, validation, or CSV export. Load `extension/` in Chrome to check UI and storage behavior.

For bug reports, include browser/version, extension version, expected/actual behavior, and fictional example input. Never share real balances, account details, or private session exports in an issue.

For new site integrations, describe the exact feature, link to its implementation, record the test date/browser/version, document limitations, and follow [the compatibility register](docs/site-compatibility.md). Do not add unrelated promotional links or claim untested compatibility.
