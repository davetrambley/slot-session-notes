# Roadmap

This is a list of possible improvements, not a release commitment.

## 0.1.0: local journal

- Manual session entry, editing, deletion, and filtering.
- Per-currency net totals with deposits and withdrawals.
- CSV export, local storage, no site access.

## Next priorities

- Versioned JSON backup and restore, with validation and duplicate detection.
- Date and currency filters.
- A Turkish interface.
- Keyboard and screen-reader feedback from real users.

## Later, after choosing and testing actual sources

- Site-specific import adapters where data formats permit.
- Explicitly requested permissions for optional page helpers.
- A verified compatibility register with independent test notes.
- Browser store submission after broader testing and release review.
